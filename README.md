# ChaosPlane Helm Charts

Helm charts for deploying [ChaosPlane](https://chaosplane.io) — open-source chaos engineering platform for Kubernetes.

## Charts

| Chart | Description |
|-------|-------------|
| [chaosplane](charts/chaosplane/) | Core platform: operator + daemon |

## Quick Start

```bash
helm install chaosplane ./charts/chaosplane
```
